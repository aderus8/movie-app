# Movie App

### University Project — Group S42-05 - 299452

Full-stack movie application built with **Python, FastAPI, PostgreSQL and React**.

## Preview

![Movie App](screenshots/home.png)

## Features

- Movie search and filtering
- Ratings and reviews
- Favourite movies and personal watchlist
- Genre-based movie recommendations
- JWT authentication

## Tech Stack

**Backend:** Python, FastAPI, SQLAlchemy, PostgreSQL  
**Frontend:** React, JavaScript, CSS
